## v0.2.0 正式发布记录

- 初次设置与日常设置分开，仪表盘、播放列表、设置共享 Dock，支持浏览器导航与未保存提示。
- 后台生成所选内容预览，支持失败重试、重启恢复；非画面设置复用缓存，已有列表自动补齐缺图。
- 城市搜索支持中文简称、全称、繁体、拼音和英文；城市区县优先，其他地点折叠，搜索失败不改变当前选择。
- 管理密码至少 6 字符，不限制字符类别，提供显示／隐藏；密码不会写入浏览器草稿。
- 新装和主动轮换自动生成六位大写字母数字设备码；升级保留已有码，签名、会话及初始化密钥仍为独立长随机值。
- A/B 两种启动能力保留；插件验证证书链及主机名，不跟随重定向。
- 八张示例由当前代码重新生成，新增拼图、当前日常设置截图及可复现脚本。天气使用演示数据，不公开私人账号、域名或设备码。
- 海外 VPS 已部署运行，旧 VPS 看板与采集器已停止。公开仓库不包含个人运维资料、授权、运行数据或日志。

## 验证与交付

93 项服务端测试通过，覆盖配置迁移、缓存、认证、城市搜索、设备码轮换、后台预览和日常设置。另验证采集器、六组 Lua、前端导航及 JavaScript 语法；Linux CI 执行真实 LuaSec TLS、全新安装、九类画面、重启及完整卷恢复。结果以正式发布提交的 [CI](https://github.com/jijuwen/kindle-glance/actions) 为准。

线上已核对中文城市搜索、管理页面、连接码显示和旧码拒绝；更新保留业务设置，其他业务容器未重建。用户已提供 Kindle 端诊断及当前世界昼夜画面反馈；尚未形成完整 A/B、RTC、断网恢复和 12/24 小时续航矩阵，不将软件测试当成长期设备实测。

发布三个 ZIP 和 SHA256SUMS，逐文件核对归档。公开内容从显式清单导出，保留自有 MIT 与第三方许可边界。
