## O-01 至 O-12 对照

| 规划项 | 实现 |
|---|---|
| O-01 地区 | settings.py 单一持久化配置，空安装无默认城市；渲染使用不可变上下文 |
| O-02 时间 | 页面、管理端、排期、订阅输入统一 IANA 时区；UTC 时间戳不重解释；DST 重复必须选择 |
| O-03 初始化 | 自动独立密钥、本机一次性码、五步向导、设置前不抓天气、启动不等待全部图片 |

| O-05 通用部署 | 根 Compose、命名卷、无作者网络依赖、默认本地监听、无强制国内镜像 |
| O-06 采集器 | Dockerfile、固定 CLI、覆盖 Compose、私有/展示/桥接三个卷、真实无账号协议检查 |

| O-12 测试交付 | CI、公开审查、安装/恢复验证、三个发行 ZIP 与 SHA256SUMS |

## 需要现场条件的稳定版门槛

1. **新版本 KPW11 真机回归**：A/B、真实 CA 与设备时钟、横竖方向、RTC/常驻、断网回睡、退出后原生界面恢复。历史设备观察不能代替新候选版测试。
2. **12/24 小时深睡和续航**：需要经过实际时长的设备测试；软件测试无法代替。
3. **真实生产副本升级和回退**：目前只有合成旧配置迁移和干净实例备份恢复。用户要求不改生产 VPS，因此未接入生产数据或凭据。
4. **真实 Codex 授权流程回归**：公开组件与协议已验证，但未为测试重新登录用户账号；安装者需用自己的账号授权并确认身份。

这些事项不隐藏为“全部通过”，本次发行明确标为 prerelease。多设备/多地点、完整英语、配对码、自动开始和独立客户端是原计划后续里程碑，未偷渡进首版；暂停的合并刷新和同图零刷新实验未恢复。
