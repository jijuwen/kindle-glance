# 年度花园

年度花园是独立的横屏看板，以每天一幅图案展现一年的生长过程。画面以白纸和黑色手绘线条为主，借鉴 One Year: Daily Journal 的花园视觉；本项目使用重绘素材与自己的排列算法，未取得原应用的源文件或原始素材库。

## 启用与选择

管理端打开「播放列表」→「添加页面 ＋」→「年度花园」。在该条目的「…」→「设置」中设置启用状态、星期和时段；需要只显示花园时，将其他条目临时隐藏。列表顺序、时段与 Smart Skip 共同决定当前显示的看板，不会因为添加新页面而删除其他配置。

原生画面为 1648×1236；KPW11 传输图片为 1236×1648，按现有协议旋转。管理端缩略图和大图预览恢复横屏方向，设备取图接口保留传输方向。

## 日期与排列

- 日期来自服务端已保存的 IANA 时区，包含当天图案；未来日期显示种子。年份、已过百分比、年内天数与剩余天数自动计算，无需手工录入。
- 顶部以日期和星期为主；年份、年内天数、剩余天数与已过百分比合并为一行灰色小字。右上角放大展示当天新长出的图案及中文名，花园内不再画今日短线；今天的位置即已长出图案与种子的交界处。
- 平年使用 365 幅不同图案，闰年在 2 月 29 日加入独立 `leap-day`，共 366 幅。年度边界与闰年由日历计算。
- 第一次渲染创建私有数据文件 `annual-garden.json`，保存实例种子。同一实例、同一年会得到固定素材顺序，刷新和重启不会重新随机排列。
- 自 2027 年起，郁金香、樱桃、草莓、树莓、睡莲、向日葵、葡萄、无花果、苹果、南瓜、橡果和雪人只出现在各自季节的月份，同一题材尽量相隔一周，其余图案仍随机分布。纬度小于 0 的南半球地区季节整体错开六个月；地区跨越南北半球时花园重新生成。2026 年及以前的花园保持原有顺序和位置。
- 整年位置提前规划：树冠枝叶较大，花卉居中，小花幼芽和果实菌菇较小。按实际图案宽度安排不等宽位置，相邻 3–5 幅形成小组，组间保留呼吸空间，高低位置错落。R6 将轮廓避让改为硬约束：每条水平扫描线保护最外侧笔画之间的区域，包含花冠内部留白及开放枝叶，轮廓间至少留出 2 像素距离；未来种子及每株下方一小段空间（原今日短线位置）也提前预留；R7 去掉短线后仍保留这段空间，已有排列不会移动。
- 先为全年每株预留可辨认的最小轮廓，再优先安排树冠枝叶、花卉和小型点缀，最后利用剩余空隙调整拥挤图案。候选位置必须无碰撞，再比较位移和缩放幅度；布局升级会重新排布一次，日图案顺序保持不变。
- 日期推进仅将对应种子换成图案，不推动此前的图案。未来种子与该图案中心对应，看似不规则，但在同一年中位置固定。

这是本项目的实现，不代表原应用具有相同的素材映射或排布规则。

## 灰度与手绘风格

| 元素 | 原生灰度（0 最黑，255 最白） |
|---|---|
| 图案主体、日期与星期、今日图案及名称 | 0 |
| 年份、年内天数、剩余天数、已过百分比及「今日」标签 | 96 |
| 未来日期种子 | 80 |
| 纸面 | 255 |

图案主线宽基准为素材坐标中的 3.7，随图案大小缩放，并有轻微压力变化。透明边缘及缩放抗锯齿会产生中间灰度，不应将全部边缘强行二值化。未来种子先从 192 调至 176，R5 收深至 100，R6 按用户确认进一步调整至 80。种子大小保持原方案，位置随新的全年布局确定。R7 调整顶部信息并在右上角展示今日图案，渲染修订为 7。

中文使用 Yozai Medium，数字及拉丁字符使用 Shantell Sans。字体文件、OFL 许可与来源校验随项目提供，见 [第三方说明](../THIRD_PARTY_NOTICES.md) 和 [素材库说明](../kindle-display/app/assets/annual-garden/README.md)。

## 素材与开发

`kindle-display/app/assets/annual-garden/` 包含 365 幅基础 SVG、透明 PNG、独立闰日图案、清单与字体。清单记录主题及校验值；这些是按参考图重绘的素材，与原作细节有差异，不应宣传为原应用素材包或完整复刻。

生成器为 `tools/build_annual_garden_assets.py`，渲染器为 `kindle-display/app/annual_garden.py`。调整素材后需同步 PNG 与清单，并递增渲染修订以淘汰旧缓存。测试覆盖素材完整性、字体、固定排列、日期推进、闰日、灰度，以及完整年份的图案轮廓、种子和预留空间互不碰撞、2026 年排列不变、季节月份和南北半球；命令见 [开发指南](DEVELOPMENT.md)。

## 缓存、备份与升级

花园按当地日历日失效，跨日、跨年或渲染修订变化后重新生成；通常不依赖小时级刷新内容。Kindle 实际显示更新仍由设备唤醒和取图决定。

完整备份需保留 `annual-garden.json`。删除或丢失实例种子会在下次渲染创建新的排列；备份也应保留设置、播放列表和原授权。升级不会自动启用新增花园，也不会改变已有列表排期。详见 [升级与回退](UPGRADING.md)。
