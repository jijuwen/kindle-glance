# 兼容与验证范围

当前正式版：服务端 0.2.0，插件 1.1.0，A/B 启动器 1.1.0。

| 组合 / 功能 | 验证范围 |
|---|---|
| KPW11 / Paperwhite 5、KOReader v2026.07.1 | 目标设备基线；有实际使用与画面反馈，完整回归矩阵仍需补齐 |
| 插件 1.1.0 电源与循环 | 六组 Lua 回归，保持原 RTC 和常驻模式逻辑 |
| HTTPS | Linux LuaSec 实际握手验证链、SAN、过期证书及重定向；设备时钟和 CA 必须正确 |
| A/B 启动 | A 普通模式，B 官方 no-framework 参数；进入 KOReader 后均需手动开始看板 |
| 12/24 小时 RTC、深睡与续航 | 尚未完成完整长期实测 |
| 其他 Kindle / KOReader 版本 | 未验证 |
| Linux Docker、非 root 卷、中文渲染 | CI 安装、九类页面、重启与完整卷备份恢复 |
| VPS 运行与迁移 | 已部署运行并验证接口；真实生产副本回退演练尚未完整记录 |

首版支持中文、单管理员、一个全局地点、单播放列表和固定 1236×1648 传输画布。正式发布不扩大上述支持范围。

服务地址应直接填写完整 HTTPS 地址。插件不跟随 HTTP 301/302，避免向其他地址转发设备码；出现 301 先检查是否填成 HTTP。

多用户、多设备、多地点、更多分辨率、英语、配对码、一键开始及独立客户端属于后续版本。合并刷新及同图零刷新实验保持暂停。
