# 故障处理

- 初始化码过期：未建立管理员时运行 `python -m app.manage renew-setup-code`；已建立管理员时正常登录。
- 首次安装提示旧配置：确认挂载的是空卷。不要把另一实例的数据目录复用为“新安装”。
- 设置损坏：停止服务，保存原文件，从备份恢复。程序不会自动清空损坏配置。
- 搜不到城市：可以用公开地图查城市级坐标后手动输入；不需要精确住址。时区使用 IANA 名称。
- Kindle 连不上：检查是否填了 localhost、服务器端口是否开放、设备与服务器网络是否互通、令牌是否轮换。
- HTTPS 失败：校准设备时钟，检查域名匹配、服务器完整证书链和设备 CA 文件。重定向被禁止，应填写最终 HTTPS 地址。
- 天气暂不可用：同地点可保留最近成功缓存并标过期；切换城市后不能借旧城市数据补充新城市。
- 中文显示异常：容器必须安装 Noto CJK。Windows 预览可设置 `FONT_PATH` 和 `FONT_BOLD_PATH`。
- 采集器未安装：基础天气与日历不受影响；按安装文档启用可选 Compose。
- 账号需要重新授权：在用量提示项目设置中重新授权并确认账号。不要把 OAuth 文件或快照贴到 issue。
- B 入口退出问题：停止看板仍在 KOReader；正常退出 KOReader 后才恢复原生 Kindle 界面。
- 自动休眠未恢复：查看插件“设置与诊断 → 恢复自动休眠”，保留 `board-power.lua` 恢复记录。

报告问题时附版本、机型、固件、KOReader 版本、A/B 入口、复现步骤以及管理页的脱敏诊断。不要附令牌、签名 URL、邮箱、Cookie、私有地址或完整日志。
