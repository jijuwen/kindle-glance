# 年度花园素材库

365 幅基础图案、1 幅独立的闰日图案和 54 幅新增图案，每幅分别保存为 SVG 矢量图和透明背景 PNG。线条为黑色；PNG 的透明度用于渲染缩小时的抗锯齿。清单、主题、参考位置和文件校验值见 manifest.json。

基础图案依据 One Year: Daily Journal 花园截图重绘，包含花草、枝叶、菌菇、果实、动物和花园小物件。这里保存的是重绘素材，未获取到原应用的 SVG 或原始素材包；图案细节与原作有差异。新增图案（编号 367–420）由本项目用同一支笔原创绘制，不依据参考截图，清单 additions 一节单独记录。

画笔与画法位于 ../../garden_drawings.py，生成程序 ../../../../tools/build_annual_garden_assets.py 用它冻结这里的编号素材。渲染程序位于 ../../annual_garden.py。源文件保留独立图案，便于后续逐幅调整。

看板按安装实例和年份生成稳定的素材排列；同一年重绘不会打乱已有位置。每年从全部 419 幅中按配额与稀有度抽取 365 幅，每一天对应一个不同的图案，未来日期显示浅灰种子。平年使用 365 幅，闰年在 2 月 29 日额外使用 leap-day。日期由看板设置的时区自动取得。

R3 构图按图案视觉重量区分树冠枝叶、花卉、小花幼芽、果实菌菇等尺寸层次，使用实际墨迹边界安排不等宽位置。相邻图案组成 3–5 幅的小组，组内靠近、组间留出呼吸空间，高低位置随小组节奏变化。拥挤处按实际线条重合量微调位置和尺寸，避免相邻轮廓过度粘连。整年位置提前规划并保持稳定，新增一天不会推动之前的图案。此策略是本项目的实现，不代表原应用的排列算法。

R6 将轮廓避让改为硬约束：按水平扫描线保护整株图案的占用轮廓，包含内部留白与开放枝叶，保留至少 2 像素距离。未来种子也参与预留。先为全年图案保留最小空间，再优先安排较大枝叶、花卉和小型点缀，最后利用空隙局部调整。每日图案顺序、素材及字体保持原方案，种子灰度按用户确认由 100 收深至 80，大小不变；升级时位置重新规划一次，之后逐日增长不会移动已有图案。R8 将全年分为 15 行、每行 24 或 25 株并铺满整个宽度，年末花园填满画面。R9 加入新增图案，形似的小野花、雏菊、浆果、多肉、苹果和风铃草每年只取一部分。R10 起这里的素材作为每天题材的底稿和退路：看板每天用同一支笔现画一幅新画法，并检查灰度与比例不超出该题材这些素材的范围。

线条保留轻微的压力变化，R3 主线宽由 4.3 收细至 3.7；内部细节同比收细。年份和百分比为灰度 96，主体线条与主要文字为灰度 0。R4 将未来种子灰度由 192 调至 176；R5 按实机试用要求继续调至 100，大小和位置保持不变。

中文采用 Yozai Medium，数字和拉丁字符采用 Shantell Sans。字体文件、OFL 许可、来源和校验值均保存在 fonts 目录，字体不依赖浏览器或操作系统安装。
