# 年度花园素材库

365 幅基础图案和 1 幅独立的闰日图案，每幅分别保存为 SVG 矢量图和透明背景 PNG。线条为黑色；PNG 的透明度用于渲染缩小时的抗锯齿。清单、主题、参考位置和文件校验值见 manifest.json。

图案依据 One Year: Daily Journal 花园截图重绘，包含花草、枝叶、菌菇、果实、动物和花园小物件。这里保存的是重绘素材，未获取到原应用的 SVG 或原始素材包；图案细节与原作有差异。

生成程序位于 ../../../../tools/build_annual_garden_assets.py。渲染程序位于 ../../annual_garden.py。源文件保留独立图案，便于后续逐幅调整。

看板按安装实例和年份生成稳定的素材排列；同一年重绘不会打乱已有位置。每一天对应一个不同的图案，未来日期显示浅灰种子。平年使用 365 幅，闰年在 2 月 29 日额外使用 leap-day。日期由看板设置的时区自动取得。

R3 构图按图案视觉重量区分树冠枝叶、花卉、小花幼芽、果实菌菇等尺寸层次，使用实际墨迹边界安排不等宽位置。相邻图案组成 3–5 幅的小组，组内靠近、组间留出呼吸空间，高低位置随小组节奏变化。拥挤处按实际线条重合量微调位置和尺寸，避免相邻轮廓过度粘连。整年位置提前规划并保持稳定，新增一天不会推动之前的图案。此策略是本项目的实现，不代表原应用的排列算法。

线条保留轻微的压力变化，R3 主线宽由 4.3 收细至 3.7；内部细节同比收细。年份和百分比为灰度 96，主体线条与主要文字为灰度 0。R4 将未来种子灰度由 192 调至 176，大小和位置保持不变。

中文采用 Yozai Medium，数字和拉丁字符采用 Shantell Sans。字体文件、OFL 许可、来源和校验值均保存在 fonts 目录，字体不依赖浏览器或操作系统安装。
